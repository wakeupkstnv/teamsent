# Teamsent

Teamsent is a fork of [herdr](https://github.com/herdrdev/herdr) (Apache-2.0),
pinned at `v0.9.3`. It adds shared sessions: `teamsent host` creates an invite
link, `teamsent join <link>` attaches a guest through a relay with roles and
host approval.

- Upstream code keeps its original license and copyright (see `LICENSE`).
- Teamsent changes to upstream files are listed in `PATCHES.md`.
- Teamsent-specific code lives in separate modules.
